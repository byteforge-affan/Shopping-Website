# Arts Store — Complete PHP Website
## Vogue Store Style | 3 Dashboards: Admin + Employee + Customer

---

## SETUP — 4 Steps

**Step 1:** Open phpMyAdmin → Import → Select database.sql → Go

**Step 2:** Open includes/db.php and set your DB password

**Step 3:** Copy ArtsStore folder to htdocs/ (XAMPP) or www/ (WAMP)

**Step 4:** Open http://localhost/ArtsStore/

## ADMIN DASHBOARD FEATURES
- Stats: Total orders, Revenue, Products, Customers
- Low stock alerts
- Orders: View all, filter by status, update status
- Products: Add / Edit / Delete
- Categories: Add / Edit / Delete
- Stock: Bulk update all stock
- Employees: Create accounts, edit, deactivate
- Customers: Full list with order history
- Feedback: View all customer messages
- Reports: Sales, top products, payment breakdown

## EMPLOYEE DASHBOARD FEATURES
- Order stats overview
- View & update order status
- Dispatch page: Confirm dispatch and delivery
- Change own password ONLY

## CUSTOMER FEATURES
- Browse products (no login needed)
- Register & Login
- Add to cart, checkout
- 3 payment types (Credit Card, Cheque, Cash on Delivery)
- 16-digit unique order number
- My Account: orders, profile, change password
- 7-day return policy
